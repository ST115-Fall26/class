Question 1 (50-points)

Please watch the following video on data visualization here .

After you have watched the entire video, please answer the following questions.

The data used in the video are pre-loaded into R, and called gapminder. You are going to both re-create a still image, and the animated version of his plot. Here are some things to consider:

The x-axis uses a logarithmic scale in the video. At the beginning, around 0:30, he introduces income values of $400, $4,000, and $40,000. Those values are equally spaced on the graph even though each is ten times the previous value. We can transform our x-axis to be on a logarithmic scale by using the function scale_x_log10() with no other arguments.

To hide the legends, as seen in the video, please see the help file for theme() and search the legend.position = argument.

Note: The gapmider data does not have any information on the Middle East. You may exclude this information for the purpose of this project.

Question 2 (10-points)

Now, we are going to re-create his animation! Please note that when you render to a PDF, your plot will not animate. Animation only works on non-static documents like a HTML document.

To do this, we are going to…

– Copy your code from question-1 part c into a new code chunk here. Save your plot as a R object, p.

– use the function transition_time() with the argument of your time variable you want your plot to animate through. This needs to be layered onto your ggplot() canvas.

– Make sure you are using the entire data set, and not the filtered data set

– Update the title of your plot to be “Year: {frame_time}”. This creates a dynamic title where frame_time is updated according to the transition_time() variable.

– This will not be supported as a pdf. Make sure to set your code chunk to echo: true and eval: false so we can still see your code. You should be able to see / enjoy your animation in the Viewer pane!

– You will see some warnings due to values being removed because they started to fall outside the limits set. This is okay for this assignment!

Note: You need to use the function animate() to actually see your animated image. For example: animate(p, fps = 10, duration = 10). Take a look at the help file for animate() for more information.
