library(tidyverse)

Motivation

For motivation, we are going to use the World Phones data set. Suppose I want to calculate the mean phone length for each year and country combination. Can I do that?

No… or at least not easily using the tidyverse.

Are these data considered wide or long? What did we learn from this exercise?

This is a wide data set! Multiple values of a variable (phone count) are stored in separate columns (region) rather than in separate rows. We only have one row per year for each region!

This makes the data harder to work with.

Pivot Practice

x <- tibble(
  state = rep(c("MT", "NC" , "SC"),2),
  group = c(rep("C", 3), rep("D", 3)),
  obs = c(1:6)
  )

x
# A tibble: 6 × 3
  state group   obs
  <chr> <chr> <int>
1 MT    C         1
2 NC    C         2
3 SC    C         3
4 MT    D         4
5 NC    D         5
6 SC    D         6

Pivot these data so that the data are wide. i.e. Each state should be it’s own unique observation (row). Save this new data set as y.

y <- x |>
  pivot_wider(
    names_from = group,
    values_from = obs
  )

Pivot the code back to its original form.

y |>
  pivot_longer(
    cols = !state,
    names_to = "group",
    values_to = "obs"
  )

Extra Practice

Let’s go ahead and reshape the WorldPhones data set so we can answer the question. To help us answer the question, we are going to introduce a function called rownames_to_column()

WorldPhones_long <- as.data.frame(WorldPhones) |>
  rownames_to_column(var = "Year") |>
  pivot_longer(
    cols = !Year, 
    names_to = "Region",
    values_to = "Phone_Count"
  )
